# Puzzle Pocket

Pixel 10などのAndroid端末で遊ぶための、個人用パズルPWAの試作です。

## 現在の機能
- 4カテゴリのホーム画面
- ひらめき問題・図形問題・論理推理のオリジナル問題
- 9×9数独の自動生成（難易度3段階、解が一意になるよう確認）
- 解答チェック、ヒント、次の問題
- 挑戦数・クリア数・正解率をブラウザ内に保存
- Service Workerによるオフラインキャッシュ

## ローカルで確認
PWA機能（ホーム画面追加・Service Worker）はHTTPSまたはlocalhostで動きます。
静的ファイルをホスティングしてアクセスしてください。

## 無料で公開してPixelに入れる方法（GitHub Pages例）
1. GitHubで新しい空のリポジトリを作成
2. このフォルダ内の5ファイルをアップロード
3. Settings → Pages → Deploy from a branch → main / root を選択して保存
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` をPixelのChromeで開く
5. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選択

問題はオリジナルの試作問題です。既存ゲームの問題文・画像・キャラクターは使用していません。
